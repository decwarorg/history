## DECWAR22.HLP 

This is an original utexas help file, identifiable by two things in the first few lines.
- There are 18 ships.
- It is a TOPS-10 command "R GAM:DECWAR" to start the game. 

## DECWAR23CIS.HLP

This is a Compuserve (CIS) help file, identifiable by two things in the first few lines.
- There are 10 ships.
- It is a non TOPS-10 command "8 DECWAR (on the MultiPlayer Host)" to start the game. Multiplayer Host is purely a Compuserve concept. There was no such thing at utexas.
